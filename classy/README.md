# Classy

แอปจัดการชีวิตนักศึกษา — ตารางเรียน งานที่ต้องส่ง ตารางสอบ และเกรด รวมอยู่ในแอปเดียว

โปรเจครายวิชา ส่ง อ.ประเสริฐศักดิ์

---

## ตรงกับข้อกำหนดตรงไหนบ้าง

| ข้อกำหนด | ทำที่ไหน |
|---|---|
| ฐานข้อมูล บันทึก / แก้ไข / ลบ | SQLite ผ่าน `sqflite` — `data/local/` + `data/repositories/` |
| เรียกใช้ API ภายนอก | Open-Meteo (พยากรณ์อากาศ) — `data/api/weather_api.dart` |
| หน้าจอ responsive | `core/responsive/` — มือถือเมนูล่าง, แท็บเล็ต/จอใหญ่เมนูซ้าย |
| หน้าแสดงข้อมูลสมาชิกกลุ่ม | `features/profile/about_screen.dart` |
| เทคนิคนอกห้องเรียน | วาดกราฟ GPA เองด้วย `CustomPainter` — `features/grades/widgets/gpa_chart.dart` |
| รันบนเครื่องจริง | `flutter run` ต่อ Pixel 8 ได้เลย |

## วิธีรัน

โฟลเดอร์นี้มีแค่ส่วนโค้ด (`lib/`) ยังไม่มีโฟลเดอร์ android / ios
ให้สร้างเพิ่มด้วยคำสั่งนี้ก่อน (รันในโฟลเดอร์ classy)

```bash
flutter create . --project-name classy
flutter pub get
flutter run
```

เปิดแอปครั้งแรก ฐานข้อมูลจะถูกสร้างและใส่ข้อมูลตัวอย่างให้อัตโนมัติ
อยากล้างข้อมูลกลับเป็นตัวอย่างใหม่ ไปที่ Profile → รีเซ็ตข้อมูลตัวอย่าง

> **ต้องต่อเน็ต** เฉพาะตอนดึงข้อมูลอากาศในหน้าแรก
> ถ้าไม่มีเน็ต แอปยังทำงานปกติ แค่แถบอากาศจะขึ้นว่าโหลดไม่สำเร็จ

**กฎง่าย ๆ ของโครงสร้างนี้**
- อยากแก้หน้าไหน เข้าโฟลเดอร์ชื่อนั้นใน `features/`
- วิดเจ็ตที่ใช้แค่หน้าเดียว เก็บใน `features/<ชื่อหน้า>/widgets/`
- วิดเจ็ตที่ใช้หลายหน้า ย้ายไป `core/widgets/`
- หน้าจอห้ามเรียก SQL หรือ HTTP ตรง ๆ ให้เรียกผ่าน `repositories/` หรือ `api/`
- ห้ามเขียนสีตรง ๆ ในหน้าจอ ให้ดึงจาก `AppColors` หรือ `Theme.of(context)`

## ฐานข้อมูล

ใช้ SQLite เก็บในเครื่อง ไฟล์ชื่อ `classy.db` สร้างอัตโนมัติตอนเปิดแอปครั้งแรก

**3 ตาราง**

| ตาราง | เก็บอะไร | คอลัมน์สำคัญ |
|---|---|---|
| `subjects` | วิชาเรียน | code, name, lecturer, room, credits, grade, color_value, days, start_time, end_time |
| `tasks` | งานที่ต้องส่ง | title, subject, due_date, done |
| `exams` | ตารางสอบ | subject, date, time, room, seat, is_final |

**ข้อควรรู้ 3 อย่างเวลาเก็บข้อมูลลง SQLite**
1. ไม่มีชนิด `bool` → เก็บเป็น `1` / `0`
2. ไม่มีชนิด `DateTime` → เก็บเป็นข้อความ ISO เช่น `2026-09-21T23:59:00.000`
3. ไม่มีชนิด `List` → ต่อเป็นข้อความคั่นจุลภาค เช่น `[1, 3]` เก็บเป็น `"1,3"`

โค้ดที่แปลงไป-กลับอยู่ใน `toMap()` กับ `fromMap()` ของแต่ละ model

**CRUD อยู่หน้าไหน**

| การกระทำ | ทำยังไงในแอป |
|---|---|
| เพิ่มวิชา | Schedule → ปุ่ม Add Subject |
| แก้ไขวิชา | Schedule → แตะที่การ์ดวิชา |
| ลบวิชา | Schedule → ปัดการ์ดไปทางซ้าย (มีปุ่มเลิกทำ) |
| เพิ่มงาน | Tasks → ปุ่ม Add Task |
| แก้ไขงาน | Tasks → แตะที่การ์ดงาน |
| ติ๊กว่าทำเสร็จ | Tasks → กดช่องสี่เหลี่ยมซ้ายมือ |
| ลบงาน | Tasks → ปัดการ์ดไปทางซ้าย (มีปุ่มเลิกทำ) |

## API ภายนอก

ใช้ **Open-Meteo** ดึงอุณหภูมิและสภาพอากาศปัจจุบัน มาแสดงในหน้าแรก

- ไม่ต้องสมัคร ไม่ต้องใช้ API key ใช้ได้ฟรีเลย
- เอกสาร: https://open-meteo.com/en/docs
- โค้ดอยู่ที่ `data/api/weather_api.dart`

```
GET https://api.open-meteo.com/v1/forecast
      ?latitude=13.7563&longitude=100.5018
      &current=temperature_2m,weather_code
      &timezone=Asia/Bangkok
```

ตั้ง timeout ไว้ 10 วินาที และดัก error ทุกกรณี
ถ้าโหลดไม่สำเร็จจะคืนค่า `null` แล้วหน้าจอแสดงข้อความบอกผู้ใช้แทน — แอปไม่แครช

## การทำ responsive

| ขนาดจอ | ความกว้าง | หน้าตา |
|---|---|---|
| มือถือ | < 600 | เมนูอยู่ด้านล่าง, การ์ดเรียง 1 คอลัมน์, ขอบซ้ายขวา 22 |
| แท็บเล็ต | 600 – 1023 | เมนูย้ายไปด้านซ้าย (NavigationRail), การ์ด 2 คอลัมน์, ขอบ 40 |
| จอใหญ่ | ≥ 1024 | เมนูซ้ายแบบมีชื่อกำกับ, การ์ด 3 คอลัมน์ |

ทุกหน้าครอบด้วย `ResponsiveLayout` ที่จำกัดความกว้างเนื้อหาไว้ที่ 900
จอกว้างมาก ๆ ข้อความจะได้ไม่ยืดยาวจนอ่านยาก

## ฟอนต์

ตอนนี้ยังไม่ได้ใส่ไฟล์ฟอนต์ แอปจะใช้ฟอนต์ default ของเครื่อง รันได้ปกติ

อยากได้หน้าตาเหมือนดีไซน์เป๊ะ ๆ:
1. โหลด **Playfair Display** และ **Inter** จาก fonts.google.com
2. วางไฟล์ `.ttf` ไว้ที่ `assets/fonts/`
3. เปิดคอมเมนต์ส่วน `fonts:` ใน `pubspec.yaml`
4. `flutter pub get` แล้วรันใหม่

## ถ้าอยากเปลี่ยนไปใช้ Firebase

โครงสร้างวางไว้ให้เปลี่ยนง่ายแล้ว หน้าจอทุกหน้าคุยกับ repository เท่านั้น
ไม่ได้คุยกับ SQLite ตรง ๆ เพราะฉะนั้น**แก้แค่ 3 ไฟล์ใน `data/repositories/`**
ให้ไปอ่าน-เขียน Cloud Firestore แทน หน้าจอไม่ต้องแตะเลยสักบรรทัด
